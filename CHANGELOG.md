# Changelog

All three packages are versioned together during initial development.

## 0.1.3 — 2026-07-25

### psyreport 0.1.1
- Declared `jinja2` as a dependency. `to_latex()` calls
  `DataFrame.to_latex()`, which pandas routes through `Styler`, which imports
  `jinja2`. Without it the call raised `ImportError`, so `to_latex()` was
  broken for anyone whose environment did not already happen to provide
  `jinja2` through another package.

### Project
- Added `.github/workflows/ci.yml`, which runs the suite on Python 3.10, 3.11,
  and 3.12 for every push and pull request, and rebuilds the documentation
  site. The README, `GITHUB_SETUP.md`, and the paper all described this
  workflow, but it had never been added; its absence is why the `jinja2`
  dependency above went unnoticed.
- Added `.github/workflows/pages.yml` and `docs/`, the generated documentation
  site published through GitHub Pages at
  https://anovabr.github.io/anova-methods/. The page carries a light and dark
  theme, a contents rail, collapsible entries for all 21 exported functions,
  and the date it was last built.
- `README.md` is now generated by `docs/build_site.py`, from the same
  introspection and the same executed examples as the site, so the repository
  landing page and the documentation site cannot disagree. Edit that script
  rather than the file.
- Recorded the Zenodo DOIs in `CITATION.cff`. Citations use the concept DOI,
  10.5281/zenodo.21566785, which always resolves to the newest release.
- Corrected `.zenodo.json`, which described the archive as identical to the
  psystats project on PyPI. The record archives the whole repository, of which
  psystats is one of three packages.

## 0.1.2 — 2026-07-25

### Documentation
- `packages/psystats/EXAMPLES.md`: all 13 public functions of `psystats`
  documented with runnable examples on the bundled dataset. The file is
  generated by executing every block and capturing its output, so the results
  shown in it are produced by the code rather than transcribed.
- `paper/`: the manuscript describing all three packages, together with a build
  script that renders it to PDF through pandoc and WeasyPrint, requiring no
  LaTeX toolchain.

### Project
- Added `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md`.
- Added `.zenodo.json` so archived releases carry proper title, authors, ORCID,
  keywords, and licence.
- Added a `.gitignore` for bytecode and packaging artifacts.

No package source changed in this release; it covers documentation and project
infrastructure only. It is the first release archived on Zenodo, so it is the
one carrying the citable DOI.

## 0.1.1 — 2026-07-18

### psystats
- Added `load_mapfre()`: a bundled teaching dataset of depression and anxiety
  symptoms in 1,957 undergraduates from Spain, Portugal, and Brazil (Afonso
  Junior et al., 2020, doi:10.1590/0102.3772e36412). All package examples now
  use it.

## 0.1.0

### psystats
- Descriptives: `describe`, `freq`, `corr_matrix` (with significance stars).
- `table1` group comparison with automatic test selection.
- Inferential tests with effect sizes: `ttest` (Cohen's d), `anova` (η², ω²),
  `chisq` (Cramér's V).
- Regression: `linreg` (standardized betas, R², F test), `logreg` (odds ratios,
  pseudo-R²).
- Risk factors: `riskratio`, `oddsratio`, `attributable_risk` (risk difference,
  ARP, PAR, PAR%, NNT).

### psymetrics
- `alpha`: Cronbach's alpha with Feldt CI, item-total stats, alpha-if-dropped,
  reverse keying.
- Factorability: `kmo`, `bartlett`.
- `efa`: exploratory factor analysis with selectable estimator and rotation.
- `cfa`: confirmatory factor analysis / SEM from lavaan-style syntax with fit
  indices.

### psyreport
- `report`: APA-7 text for 15 result kinds, covering everything `psystats`
  emits and all of `psymetrics` except the `kmo` and `bartlett` factorability
  checks.
- `to_latex`, `to_docx`: LaTeX and Word table export.

### Validation
- 50 tests validating estimates against scipy, statsmodels, factor_analyzer, and
  semopy, plus closed-form identities.
